## Инструкция по установке

1. Клонируйте репозиторий:

   git@github.com:mishchuksergey/HomeWork-11.1.git

2. Установите зависимости:

    pip install -r requirements.txt

### Новые функции

   В домашнем задании добавлен новый модуль *decorators .py*, в котором 
   реализованы новые возможности:

    - Реализован декоратор log
    - Декоратор может логировать работу функции и ее результат как в файл, так и в консоль.
    - Декоратор logпринимает необязательный аргумент filename, который определяет имя файла, в который будут записываться логи.
    - Если filename не задан, то логи выводятся в консоль.
    - Если вызов функции закончился ошибкой, записывается сообщение об ошибке и входные параметры функции.
